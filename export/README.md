This folder in the GitHub repo holds the manifest, credits, import notes, and the starter Unity script.

The full engine pack (`terrain/` GLB chunks and 16-bit RAW heightmaps, `roads/`, `rail/`, `buildings/`, `landcover/`) is **`/workspace/ogden/ogden-environment.zip` (63 MB)** on the build machine. It is not in this git repository because it exceeds GitHub’s 50 MB per-file limit. The web prototype here already includes the feature GLBs, web heightmap, splat, and landuse masks needed to play in the browser.
